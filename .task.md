# Add sitemap.xml, robots.txt, and JSON-LD structured data

## Summary

Add SEO metadata surfaces for the portfolio:

- Generate `sitemap.xml` from maintained route data.
- Generate `robots.txt` with a sitemap link and API crawl exclusion.
- Add JSON-LD structured data for the site owner, portfolio home page, and projects page.

## Requirements

- Keep sitemap URLs absolute and based on `siteConfig.url`.
- Include the core pages: `/`, `/projects`, `/scrollable`, and `/playground`.
- Include linked playground game routes in the sitemap.
- Keep `/api/` disallowed in `robots.txt`.
- Emit JSON-LD safely with escaped script content.
- Add portfolio home page structured data without forcing the whole page to be a client component.
- Add projects page structured data that covers every project in `PROJECTS`.

## Implementation Plan

1. Add shared SEO helpers in `src/lib/seo.ts`.
2. Replace inline root JSON-LD data with reusable builders.
3. Split the home page into a server page wrapper plus a client component so JSON-LD can render at the route level.
4. Update `src/app/sitemap.ts` and `src/app/robots.ts` to use shared SEO URL helpers.
5. Add projects page JSON-LD through `src/app/projects/layout.tsx`.
6. Add focused unit tests for sitemap entries, JSON-LD coverage, and JSON-LD script escaping.

## Acceptance Criteria

- `sitemap.xml` includes core portfolio pages and playground game routes.
- `robots.txt` links to the sitemap and disallows `/api/`.
- Root layout includes site-level Person/WebSite JSON-LD.
- Home page includes portfolio ProfilePage/WebPage JSON-LD.
- Projects page includes CollectionPage and ItemList JSON-LD for all portfolio projects.
- Type check passes.
- Test suite passes.
